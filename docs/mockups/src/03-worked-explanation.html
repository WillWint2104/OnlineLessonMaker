Worked explanation

Find every point on y = x2 at a height of 9

On this curve the height of a point is its y-value, and every point has coordinates (x, x2).

  1. Set the height equal to 9, which gives the equation x2 = 9.
  2. Solve it: x = 3 or x = −3, because −3 × −3 is also 9.
  3. Those two x-values are the same distance either side of the y-axis, so the parabola reaches height 9 twice.
  4. The curve therefore passes through (3, 9) and (−3, 9).
Check each answer by substituting back: 32 = 9 and (−3)2 = 9.
