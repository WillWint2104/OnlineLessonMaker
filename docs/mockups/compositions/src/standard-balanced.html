Reading a value from a described situation

Question

A stone is dropped from a bridge. The distance it has fallen, in metres, is modelled by d = 5t2, where t is the time in seconds since it was released.

The bridge deck is 45 metres above the water, and the model is only trusted while the stone is still falling.

Find how far the stone has fallen after 2 seconds, and say whether it has reached the water by then.

Worked solution

  1. Write the rule and substitute t = 2.
    d = 5(2)2
  2. Square first, then multiply. The 5 is not squared.
    d = 5 × 4 = 20
  3. Compare with the height of the deck.
    20 < 45
Answer20 m — still 25 m above the water.

What this shows

Substituting into a model answers a question about the situation, not only about the algebra: the last step is the comparison that turns 20 into "not yet".
