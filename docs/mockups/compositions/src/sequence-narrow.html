Compare substitution with a negative value, a fraction and a decimal.

A negative value

Question

Use the rule y = x2 to find y when x = −4.

Worked solution

  1. Write the rule.
    y = x2
  2. Substitute the given value. Keep the brackets — the whole of −4 is squared.
    y = (−4)2
  3. Evaluate. A negative multiplied by a negative gives a positive.
    y = (−4)(−4) = 16
Answery = 16, so (−4, 16) lies on the graph.

A fraction

Question

Use the rule y = x2 to find y when x = 3/2.

Worked solution

  1. Substitute. The whole fraction is squared, not just the numerator.
    y = (3/2)2
  2. Square the top and the bottom.
    y = 32/22 = 9/4
  3. Squaring a value above 1 makes it larger; this one lands just above 2.
    9/4 = 2.25
Answery = 9/4, so (3/2, 9/4) lies on the graph.

What the three show

Substitution never changes the rule — it only replaces x. The brackets keep the whole value together.
