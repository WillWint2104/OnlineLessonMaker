State 1 — Workings

Solving by inspection

Question

Solve x2 = 16.

{{DIM:prompt}}

Worked solution

  1. Ask which numbers square to 16.
    x2 = 16
  2. Take the square root of both sides. Squaring destroys the sign, so the root must carry both.
    x = ±4
  3. Check each one back in the original equation.
    42 = 16    (−4)2 = 16
Answerx = 4 or x = −4

Why it agrees

Solving x2 = 16 asks where the curve y = x2 reaches a height of 16.

x = ±4

Draw the horizontal line y = 16. It crosses the curve twice, at x = −4 and x = 4 — the two values the algebra produced.

The two crossings sit at equal distances either side of the y-axis. That is the graph saying the same thing as the ± in the working: squaring destroys the sign, so the solutions are a mirror pair rather than two unrelated numbers.

The height of the line is what decides how many solutions there are. Above the vertex it crosses twice. Through the vertex it touches once, which is the case x2 = 0. Below the vertex it never meets the curve at all — which is what a negative right-hand side would mean, and why x2 = −16 has no real solution.

Reading the question both ways is the point of the check: the algebra gives the values, and the graph says why there are exactly that many of them.
