Completing the square

Question

Solve x2 + 6x − 7 = 0.

{{DIM:prompt}}

Worked solution

  1. Start from the equation as given.
    x2 + 6x − 7 = 0
  2. Move the constant to the right so the left side is only the terms in x.
    x2 + 6x = 7
  3. Halve the coefficient of x and square it. That is the number which completes the square.
    (6 ÷ 2)2 = 9
  4. Add it to both sides so the equation still balances.
    x2 + 6x + 9 = 16
  5. The left side is now a perfect square.
    (x + 3)2 = 16
  6. Take the root of both sides, carrying both signs.
    x + 3 = ±4
  7. Solve each case separately.
    x = 1   or   x = −7
Answerx = 1 or x = −7
