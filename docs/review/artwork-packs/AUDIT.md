# Artwork audit — before behaviour changes

Baseline: `fc27e03f2251b63aeac21cda10fc9cd4d1fa7cdb`. Inspected actual source, not inferred from screenshot names.

- Catalogue: `src/mathematics/micro-lesson/micro.js`, embedded by `scripts/build-mathematics-micro.mjs` between MATHEMATICS_MICRO markers in `lesson-studio.html`. Three IDs: `mathematics/algebra/general`, `mathematics/algebra/signs`, `mathematics/algebra/factorisation`.
- All three roles (`overview`, `outcomes`, `completion`) produce local base64 SVGs, 960×600, grid/circle/abstract geometry, mint/green, no instructional formulas. Role phase changes vertical composition. This procedural system is the reference for this task. The supplied PNG family in `assets/mathematics/` is separate, explicitly authored imagery and is untouched.
- `lpRoleImage` checks a valid explicit string/object image source first; otherwise it calls `MathMicro.image`. Object metadata overlays pack defaults. Current defaults: cover, empty decorative alt, focus `{x:.68,y:.5}`. `lpImage` uses existing `mFit`, `mFocus` and `tpFocusStyle` (clamped/rounded percentages). The .68 focus belongs to these pack images, not a global image default; unspecified custom-image focus remains centred.
- Overview and Outcomes call the same role adapter; textbook Completion calls it too. `lpBookStudentData` resolves role defaults into the cloned learner data. Data URIs already contain every SVG byte; the normal single-file exporter includes the application and resolves explicit local/remote images through its existing embedding path. There is no pack image host or runtime image fetch.
- Existing inspector selects a pack only for Mathematics, shows explicit role-image fields/upload/remove controls, but does not preview pack defaults or explain fallback. Removing an explicit source already returns to a pack. JSON uses only `meta.artworkPack`; no second image schema is needed.
- Existing validation rejects every unknown pack ID. Missing pack yields no artwork. Mathematics generation/lint and pack artwork share one module today; only the finite catalogue, procedural image function and deterministic lookup need become subject-neutral infrastructure. Generation/composition stay Mathematics-specific.

Bounded implementation: extract the original SVG function unchanged into a reusable embedded module; retain legacy byte outputs and adapter; add one `global/general`, a `mathematics/general` alias and an abstract fractions arrangement using the same grid/colours/shapes. Resolve a requested topic by progressively broader `/general` IDs, then `global/general`; absent request still returns nothing. Add resolved previews and global-only selection outside Mathematics in existing inspector surfaces. No learner-layout or production-lesson edits.
