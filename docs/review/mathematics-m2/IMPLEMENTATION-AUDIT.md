# Authoritative calculator audit — before application changes

Source: newly supplied HGL `build/calculator.html`, 383,499 bytes; SHA-256 `dd7ba18759110d309f19fda0f0a625a73537d21ba0171c962540a2423352bbe5`. The unchanged reference is retained at `assets/vendor/hgl-calculator/calculator-reference.html`. It supersedes all earlier calculator references. Production baseline: `0765310047a5b67a24f59e13002ce7c773d2d24e`, confirmed against GitHub main.

The source is a classic-script bundle with embedded module markers: legacy calculator, calc-core, calc-templates (structured input), calc-undo, calc-stats, calc-dist, calc-table, calc-complex, calc-vector, calc-spreadsheet, calc-inequality, calc-ui, calc-ui-v2 and calc-catalog. Its two calculator stylesheets sit after HGL tokens and general suite styles. The usable Calculate interface is the completed V2 Basic keypad; Advanced is not a separate supported keypad.

All eight home tiles are ready: Calculate, Statistics, Distribution, Table, Complex, Vector, Spreadsheet and Inequality. The real-number evaluator uses a tokenizer and shunting-yard/RPN parser with own-property function/variable whitelists. Complex expressions have their own supplied parser. There is no eval, Function constructor or external JavaScript dependency. Native HTML templates render fractions, roots, powers and calculus input; no MathLive dependency exists. Table values and the inequality number line are intrinsic calculator features, not the deferred M3 sketch system.

Input consists of nested atoms, named template slots and a cursor path. Undo/redo retains up to 50 input snapshots. History is capped at 50 entries, with safe replay and per-result fraction/mixed/DMS formatting. A–F, x/y/z, M and Ans are runtime variables. Angle preferences and the editable statistics, distribution, table, complex, vector, spreadsheet and inequality datasets are separate runtime objects. Standalone autosave functions are no-ops; it uses no browser storage.

Opening deliberately lands on HOME with Basic selected, preserving history and preferences. Fullscreen is an instrument layout, not the browser fullscreen API. The standalone full-frame CSS hides the source close control; its boot-error handler replaces the entire body. Those shell assumptions must be removed. The legacy launcher expects `#wl-c`; widget drag/resize is guarded and absent in standalone. Generated inline handlers expect global calculator functions. Root selectors and delegated keyboard/click handlers otherwise use document, with window flags preventing duplicate listeners.

Keyboard input supports digits/operators, Enter/=, Backspace, arrows, expression-clearing Escape, template traversal, F11 expansion and Ctrl/Cmd+L Home. Native mode input fields keep their native typing. The lesson integration must isolate all keys, restore focus after source rerenders, contain focus, and retain Escape's expression-clear behavior when Calculate handles it. Close controls and unhandled Escape close the utility.

The source's only remote dependencies are Google Fonts: Manrope, Plus Jakarta Sans and JetBrains Mono. Material Symbols is already an embedded WOFF2 subset. Integration packages the three font families locally and embeds their bytes, copyright notices and complete OFL licence texts for independent exports. No public CDN or runtime calculator host is needed. Existing OLM fonts are different families, so substituting them would change the supplied instrument.

Integration boundary: deterministic extraction of the supplied calculator modules and calculator CSS into one closure factory, using a Shadow DOM root instead of global document selectors. Retain the original reference as provenance; generated code must be reproducible and must not become a separately maintained engine. A native modal utility contains the shadow component. Lazy initialization occurs on first open. Lesson-owned runtime survives page navigation; new lesson identity or refresh resets it. Authored JSON records availability only. Initialization failures stay inside the utility.

Test boundaries: parser arithmetic/malformed input; structured templates/undo/history/variables; representative results in all eight modes; focus/keyboard/touch; navigation/reopen/reset; author disable and JSON round-trip; independent learner export; actual-size responsive and native-zoom captures; frozen lesson content and non-Mathematics regressions. M1 architecture, image bytes/focal settings, answer policies, Supabase and M3 remain outside this change.
