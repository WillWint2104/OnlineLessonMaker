# Current graphical authoring coverage

This table supersedes the historical limited-inspector report under `../shared-player/`. The shared activity player uses its registered authoring contract and a nested binding context for the existing mathematics outline, notation controls, table form and graph/object form. It does not copy the mathematics renderer or introduce a second schema.

| Area | Visible UI operations | Evidence / boundary |
|---|---|---|
| Lesson and skills | New activity lesson; Add skill; lesson/skill titles; skill earlier/later/remove | Blank-document walkthrough builds two skills; a temporary third skill is removed. The final skill cannot be removed. Skill removal requests confirmation. IDs are retained during reorder. |
| Activities | Explanation/source, worked examples, practice, one optional skill-video slot; title/introduction; earlier/later/remove | Every offered choice creates editable starter content. Temporary activity reorder/removal is verified. The last activity is guarded; removal requests confirmation. Content sections can be combined in one activity. |
| Notes/source context | Select, add, edit, reorder/remove heading/body items; existing string attribution/source/citation fields | Only the selected item's fields are expanded. Body text can include attribution. Existing attribution metadata is editable and preserved; this does not introduce a new source-rendering platform. |
| Worked content | Existing group compositions, example questions/answers/titles, step text/math/notes, representations; add/remove/reorder | Uses the existing collapsible mathematics outline with rebased binding paths. Existing examples/steps keep their IDs. Legacy bare `examples[]` has an explicit Organise action which moves its original objects into a group without simplifying them. String steps and question/result aliases remain editable. |
| Notation | Existing symbol insertion and live mathematical preview | Same `inMath`, expression preview and renderer. Strings remain the expression model; no structural equation editor was added. |
| Practice | Prompts, authored practice instructions, string subparts, stacked layout; add/remove/reorder questions and subparts | Whole-data assertions distinguish actual edits from outline changes. Non-string imported subparts are retained and identified as outside this text-part editor. |
| Instructional tables | Existing headings/cells, row add/remove and column add/remove/count controls | Same table form at group/example/step scope. Legacy array-form rows are edited in their original representation; structural row/column edits may normalise rows to the already-supported object representation while retaining their values. |
| Question tables | Add/remove table; same heading/cell/structure controls | Filled cells are instructional values; empty cells are learner blanks. Stored student answers are not changed by these controls. |
| Graphs | Existing group graph creation; domain, grid, callouts, curve names; supported function/line/points/segment fields, labels and pens; object add/remove/reorder | Same extracted graph/object form also edits imported graphs inside example/step companion parts. Legacy `points`, `from/to`, `expr` values are respected. No Figure Engine capability was added. Other imported figure families have an explicit preservation/JSON-only notice. |
| Rich imported fields | Unedited fields, companion wrapper metadata and rich relationship-item metadata retained | Deep whole-object comparisons cover source metadata, example provenance, point aliases, segment endpoints, wrapper metadata and rich relationship items. Filtered null companion slots retain their raw indexes during example/step editing, moving and deletion. Unknown fields are not automatically replaced with simplified structures. Fields without a delivered editor remain JSON-editable. |
| Video | Add optional-video slot to a new skill; edit/clear skill URL; remove slot through activity controls | One optional slot offered per skill. Empty slots remain visible for author setup and are omitted for learners. Test URLs are cleared; actual teacher/provider playback remains unverified. |
| Response policy | Saved paper/typed/pen selector; existing type/write aliases accepted | Authoring and temporary Study/Edit switches preserve all five policy values. Existing player tests cover actual response retention, workbooks and paper rendering. |
| Preview and publication | Study/Present uses the learner renderer; JSON export/reopen; independent learner HTML export | Fresh-context reopen followed by nested step/table edits is verified. Published browser title uses lesson metadata; authoring application title remains Lesson Studio. Published HTML is learner-only, and session responses are not exported. |

## Backlog

Tablet question-reference enhancement is deferred by request. Editing every possible future/non-graph figure, non-text question part or arbitrary imported metadata field is not claimed. JSON remains supported for those boundaries; supported operations above no longer require moving content into a legacy standalone page.
