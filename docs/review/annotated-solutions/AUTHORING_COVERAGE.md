The application remains `lesson-studio.html`; exported learner HTML is not a substitute for the editor.

| Operation | Evidence |
| --- | --- |
| Edit working, explanation and caution separately | Recorded visible inspector controls; multiline working preview uses the same formatter as the player. |
| Move a paired step | Move-down and move-up controls; full object equality checks include its ID, mathematics, annotation, caution and attached table. |
| Edit a candidate table at its reasoning step | Nested table outline selection and visible stub-field edit; table remains under the same step. |
| Save, reopen and edit again | Actual JSON download, fresh browser context, UI import, full-data equality, another visible caution edit. |
| Independent learner publication | Actual Export download opened in an offline fresh browser context, complete lesson equality and paired-component assertions. |
| Reveal editing fields on selection | Step, table, graph and question-part controls measured before typing, from several starting inspector scroll positions. |
| Preserve unknown structures and response policies | Existing activity-authoring gate retains richer imported metadata, wrapper forms, raw companion indexes and paper/typed/pen policies; the full suite covers response storage. |
| Reject empty learner sequence | Original optional-video-only reproduction plus tests in both modes, an empty skill among valid skills, valid content with missing optional video, and draft saving/reopen. |

JSON import establishes review fixtures; it is not claimed as graphical lesson construction. The authoring recording demonstrates edits and structural operations through visible controls. Read-only state inspection verifies results. The older two-skill creation workflow is still covered by the existing authoring regression gate and historical PR #156 recording.

The example evidence-placement selector reuses existing visual parts. `question` is additive; absent/`working` retains compatibility. No new mathematical structural format or solver was added. General graph and legacy page editors remain available. Teacher videos and the tablet question-reference enhancement remain outside the completed scope.
