| Operation | Control / evidence |
| --- | --- |
| Choose Auto, A or B | Edit → current worked activity → group → example → Question / evidence layout; preview updates on change |

| Export/reopen | Actual JSON download, fresh browser context import, further example edit, standalone learner export |
| Imported unknown data | Example metadata, visual wrapper metadata and a null raw slot retained through switch/reorder/export/reopen |
| Response data | A deliberately seeded response-store entry survives real inspector composition changes; existing response-suite tests exercise learner input separately |

The source extract and seedling image demonstrate shared compositions beyond mathematics. The seeded response check is an integrity test, not a claim that typing an answer occurred in a paper-only example.

Existing figure expansion, point callouts, tables and solution/method controls continue through their registered wiring. Composition A/B is not a drag-and-drop editor. Switching layout never recreates a graph/table or changes response IDs.
