## Runtime and publication

OpenSeadragon **6.1.1**, BSD-3-Clause, is pinned from the official package. Its inert payload travels inside the authoring HTML and initializes only on Inspect. No viewer CDN, map engine, npm runtime installation or build step is required. The licence also travels with single-file exports. Exports with no inspectable sources omit the payload. See `PUBLICATION.md` for measured bytes and the local-tile boundary.

Ordinary imported JPEG/PNG assets are embedded and work without network in independent exports. The authenticated source record URLs are links requiring internet. Existing unrelated external videos/models are not certified offline by these tests. Local-pyramid inspection requires its tile files and a local HTTP server; a standalone HTML instead inspects its embedded preview, with an explicit message. There is no automatic new asset-package publication architecture.

## Evidence

`workflow/results.json` contains the local viewer/editor/publication checks; `workflow/publication-results.json` contains local PNG pyramid, fallback, keyboard isolation and genuine Chromium native 100%/200% zoom checks. Native zoom is browser preferences, not CSS zoom. Native captures use the complete browser surface (1514×862 device pixels); at 200% the CSS viewport is 757×431. This avoids the default automation capture cropping the enlarged surface. Captures include 1536×960, 1024×768 and 390×844. The source pane scrolls independently in the existing lesson shell; inline start/end captures are distinct from fit-source inspection.

The AWM posters remain their original 426×654 and 428×654 derivatives. Inspection openly identifies their limited resolution; no missing detail has been invented. The Science fixture is 3200×1800 and its local PNG pyramid is generated from that exact source. The tests include square and document-like native sources and a missing-source fallback.

## Boundaries

No maps, hotspots, annotation authoring/capture, analytical comparison system, IIIF ingestion, videos, tablet question-reference enhancement, curriculum expansion or theme were implemented. Future annotations can reference the source's stable `id`, not modal pixels or vendor viewport values.

Formal screen-reader/AT certification, school-network policy testing and physical-tablet touch testing remain outstanding. Automated Chromium keyboard, focus, native zoom and responsive checks are evidence for those tested behaviours, not a full WCAG claim. The existing low-resolution archive derivatives are sufficient for demonstrating the contract, not fine-print transcription.
