# Mathematics video → micro-lesson JSON

Use a short video for one thesis, normally one video and one to three core skills. Demonstrated examples are evidence of a method; do not turn each example into a separate destination. A fourth skill requires a written pedagogical rationale (`slide.microRationale`). Do not broaden a technique into a textbook chapter.

1. Record the video URL and available evidence. Identify the thesis and demonstrated examples; distinguish teacher-provided material from independently viewed/transcribed content.
2. Cluster examples into at most three instructional skills by default. Select one complete representative example per skill. Other demonstrations inform practice variants or optional support.
3. Reuse single-example activities, `exampleCollections.members`, `practiceCollectionId` and question `archetypeId` links. Set the Mathematics skill page's `practiceComposition` to `micro` and `meta.practiceLayout` to `textbook`. No copied example/response state is created. Edit mode retains the source activities; learner navigation hides the linked standalone examples and houses each example immediately above its practice.
4. Set each representative example's `practice.instructions` from that skill. Do not inherit unrelated expansion instructions. The linked collection names and tabs are learner-facing core skills; internal archetype identifiers stay in JSON.
5. Choose a deterministic family and explicit count overrides under `example.practice.generator: {family, counts:{basic,moderate}}`. Defaults for this acceptance fixture are 8 + 4 per skill. The supported rational families are `reverse`, `factor`, `opposite`; counts are integers 0–24 per level, with at least one realised question per skill. Scripts or the explicit authoring button realise the arrays. Learner rendering never generates questions. IDs are stable prefixes of example ID, level and parameter index; final JSON carries full stem, answer, worked answer, level and compact presentation.
6. Inspect every realised question. Regeneration replaces that skill's questions only, after confirmation; edits to those questions are replaced. Save JSON to preserve edits. One optional guided multipart question is appropriate only when it adds useful scaffolding; this fixture uses none because its representative examples supply the scaffold.
7. Use explicit `$…$` math, e.g. `$\frac{b-a}{a-b}$`, with balanced braces and supported notation. This routes through the existing TPMath parser/MathML renderer. No global prose slash conversion occurs. Generated rational families reject slash-style math; the lint's negative calibration is part of the focused gate. Include denominator restrictions and preserve the original domain after cancellation.
8. Pick `meta.artworkPack`: `mathematics/algebra/general`, `mathematics/algebra/signs` or `mathematics/algebra/factorisation`. These are proposed reusable visual variants for this review, not a claim of prior visual approval. They supply decorative Overview/Outcomes/Completion SVGs with no instructional formulas. Existing/custom role images with a nonempty `src` override defaults, including their authored alt, fit and focal settings. Export deliberately resolves missing roles into embedded data images; no local-only pack paths or remote image dependencies are published.
9. Validate unique IDs, deterministic prefixes/counts, answers and intermediate identities, restrictions, fraction/exponent rendering, lesson-specific instructions, navigation and authoring/export round-trip. Inspect full grids at 1536/1024/390 and genuine browser 200% zoom. Keep existing lessons opt-out and run compatibility gates.

For this lesson: direct reversal → factor then reverse → opposite denominators. Difference of squares appears only in Moderate within “Factor first”; addition/subtraction share “Opposite denominators”. Do not claim automatic marking or rewrite the Answer Hub/release policy.

## Reproduce

From the repository root, run `node scripts/build-mathematics-micro.mjs`, `node scripts/generate-mathematics-micro.mjs`, then `node scripts/verify-mathematics-micro.mjs`. The last command uses the real authoring export and produces runnable before/after learner HTML, original-resolution captures, round-trip JSON and results. Use `MICRO_REVIEW_DIR` for an alternate output directory. Default fixture source is the preserved `workflow/before.json`.
