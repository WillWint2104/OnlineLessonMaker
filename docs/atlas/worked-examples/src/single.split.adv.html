A one-line prompt in a split

Scenario

Find y when x = −4.

Worked solution

  1. Write the rule.
    y = x2
  2. Substitute the given value, keeping the brackets.
    y = (−4)2
  3. Evaluate.
    y = 16
Answery = 16

What this shows

The template did not change. An author who asks for a split gets a split, and the space beneath a short prompt is reading margin.
