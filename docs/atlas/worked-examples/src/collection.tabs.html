What the three show

Substitution never changes the rule — it only replaces x. The brackets keep the whole value together: a negative loses its sign when squared, a fraction is squared top and bottom, and a decimal below 1 gets smaller rather than larger.

The synthesis stays visible whichever example is open, because it is about all three.
