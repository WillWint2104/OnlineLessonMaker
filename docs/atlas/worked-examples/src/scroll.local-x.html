INDIVISIBLE MATERIAL. A table of values and a line of expansion that cannot be broken without destroying what they are for. Each scrolls sideways inside its own region; neither widens the page, shrinks the type, or changes the composition around it.

Reading y = x2 − 4 from a table

Question

Complete the table for −9 ≤ x ≤ 9, and use it to say where the curve crosses the x-axis.

Worked solution

  1. A table of values is a row of paired readings. Wrapping it onto two lines separates each x from its y, so it scrolls sideways instead.
    x−9−8−7−6−5−4−3−2−10123456789
    x28164493625169410149162536496481
    y = x2 − 477604532211250−3−4−305122132456077
  2. The crossings are the columns where y is zero.
    x = −2 and x = 2
  3. Checking against the factorised form, written out in full before collecting.
    (x + 2)(x − 2) = x × x + x × (−2) + 2 × x + 2 × (−2) = x2 − 2x + 2x − 4 = x2 + (−2 + 2)x − 4 = x2 + 0x − 4 = x2 − 4
AnswerThe curve crosses at (−2, 0) and (2, 0).

What this shows

Horizontal overflow is a last resort for material that genuinely cannot be divided. It is never a way to avoid designing a composition, and the surrounding page still does not scroll sideways.
