Practice — substitution into y = x2

Keep this in view

Every question below uses the same rule. Write the rule first, substitute with brackets, then evaluate.

y = x2

Brackets matter because the whole value is squared, sign included. −42 and (−4)2 are different numbers, and only the second one is what substituting x = −4 means.

A negative x always gives a positive y. A value between −1 and 1 always gives a y smaller than the value you started with.

Questions

  1. Find y when x = 3.
  2. Find y when x = −3.
  3. Find y when x = 0.5.
  4. Find y when x = −0.5, and say how it compares with the previous answer.
  5. Find y when x = 2/3.
  6. Find y when x = −7.
  7. Which values of x give y = 25?
  8. Which values of x give y = 0?
  9. Explain why no value of x gives y = −9.
  10. Find two values of x whose y differs by 16.
  11. A point on the curve has y = 1.44. Give both possible x.
  12. Is (−1.5, 2.25) on the curve? Show the substitution.
