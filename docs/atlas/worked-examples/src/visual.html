Reading the graph

The curve crosses the x-axis wherever y = 0, so the crossings are the solutions of x2 − 4 = 0.

x = −2 or x = 2

Those are exactly the values that make each bracket of (x + 2)(x − 2) zero, which is why factorising and reading the graph give the same two answers.

The lowest point of the curve is (0, −4), four units below the axis — the constant term of the rule, and the reason the curve has to cross twice on the way back up.

This figure is portrait: it is taller than it is wide at equal unit scale, so the composition puts it beside the reading rather than above it. That is the figure's own geometry deciding, not the length of this paragraph.
