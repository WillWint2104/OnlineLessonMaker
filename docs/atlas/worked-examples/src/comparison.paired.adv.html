Two cases of very unequal length. They are a comparison because the author said so.

Case A — by inspection

Question

Solve x2 = 16.

Worked solution

  1. Ask which numbers square to 16, carrying both signs.
    x = ±4
Answerx = 4 or x = −4

Case B — by completing the square

Question

Solve x2 − 8x = 0 by completing the square, so the method can be compared with inspection.

Worked solution

  1. Halve the coefficient of x and square it.
    (8 ÷ 2)2 = 16
  2. Add it to both sides.
    x2 − 8x + 16 = 16
  3. The left side is a perfect square.
    (x − 4)2 = 16
  4. Take the root, carrying both signs.
    x − 4 = ±4
  5. Solve each case.
    x = 8  or  x = 0
Answerx = 0 or x = 8

Why they agree

Both methods land on the same pair of solutions. Inspection is quicker when the equation is already a perfect square; completing the square works whether it is or not.
