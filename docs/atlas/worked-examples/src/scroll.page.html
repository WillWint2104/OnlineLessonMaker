Why x2 = 16 has two answers

{{PART:_solve16}}

What this shows

The ± is not a convention bolted onto the square root. It is the record of a fact about squaring: two different numbers can arrive at the same square, so undoing a square has to return both of them.

A student who has only ever seen √16 = 4 will reliably lose one solution in every quadratic they meet for the next two years. The cost of explaining it properly here is a taller page, which costs nothing.

The same question asked backwards

Question

For which values of k does x2 = k have two solutions, one solution, or none?

Worked solution

  1. Read the question as a horizontal line at height k meeting the curve y = x2.
    y = k
  2. Above the vertex the line cuts both arms of the curve.
    k > 0   →   two solutions
  3. Through the vertex the two crossings have met.
    k = 0   →   one solution, x = 0
  4. Below the vertex the line misses the curve entirely, because nothing squares to a negative.
    k < 0   →   no real solution
AnswerTwo if k > 0, one if k = 0, none if k < 0.

What this shows

The number of solutions is a question about height, and the graph answers it at a glance. This is the same fact as the discriminant, three years early and without the formula.
