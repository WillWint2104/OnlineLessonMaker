# Teacher answers — factorising quadratics

Keep this guide separate from the learner lesson. Equivalent factor orderings are correct. Students should show their chosen pair and factorisation, including splitting and grouping for non-monic quadratics. Detailed searching and expansion are optional support unless a task explicitly requests them; an answer alone does not demonstrate the method.

## Guided completion

Monic: the sums are 16 and 8. Select 3 and 5: x² + 8x + 15 = (x + 3)(x + 5).

Non-monic: a = 2, b = 9, c = 10, so ac = 20. The sums are 21, 12 and 9. Select 4 and 5. One valid chain is 2x² + 9x + 10 = 2x² + 4x + 5x + 10 = 2x(x + 2) + 5(x + 2) = (2x + 5)(x + 2).

## Independent practice

### monic practice positive

a. x² + 5x + 6 = (x + 2)(x + 3)

b. x² + 9x + 20 = (x + 4)(x + 5)

c. x² + 11x + 24 = (x + 3)(x + 8)


### monic practice negative

a. x² − 8x + 12 = (x − 2)(x − 6)

b. x² − 9x + 14 = (x − 2)(x − 7)

c. x² − 11x + 30 = (x − 5)(x − 6)


### monic practice mixed

a. x² + 3x − 10 = (x + 5)(x − 2)

b. x² − 2x − 24 = (x − 6)(x + 4)

c. x² − x − 30 = (x − 6)(x + 5)


### monic practice common

a. 2x² + 12x + 16 = 2(x + 2)(x + 4)

b. 3x² − 3x − 18 = 3(x − 3)(x + 2)


### nonmonic practice positive

a. 2x² + 5x + 2 = (2x + 1)(x + 2)

b. 3x² + 10x + 3 = (3x + 1)(x + 3)

c. 4x² + 8x + 3 = (2x + 1)(2x + 3)


### nonmonic practice negative

a. 6x² − 7x + 2 = (3x − 2)(2x − 1)

b. 2x² − 9x + 4 = (2x − 1)(x − 4)

c. 3x² − 14x + 8 = (3x − 2)(x − 4)


### nonmonic practice mixed

a. 2x² + x − 6 = (2x − 3)(x + 2)

b. 6x² + x − 2 = (3x + 2)(2x − 1)

c. 4x² − 4x − 3 = (2x − 3)(2x + 1)


### nonmonic practice common

a. 4x² + 14x + 6 = 2(2x + 1)(x + 3)

b. 6x² − 6x − 12 = 6(x − 2)(x + 1)


### monic practice explain

The proposed product has linear coefficient 1 instead of -1. Correct factorisation: (x − 4)(x + 3).

### nonmonic practice explain

The proposed product has linear coefficient 7 instead of 8. Correct factorisation: (3x + 2)(x + 2).

### monic practice area

Area = (x + 3)(x + 7) cm². Length = (x + 7) cm. At x = 2, width = 5 cm and length = 9 cm, so perimeter = 2(5 + 9) = 28 cm.

### nonmonic practice area

Area = (x + 2)(2x + 3) m². Length = (2x + 3) m. At x = 3, width = 5 m and length = 9 m, so perimeter = 2(5 + 9) = 28 m.
