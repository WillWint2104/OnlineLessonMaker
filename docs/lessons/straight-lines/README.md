# Straight lines — teacher guide

Open [the learner lesson](../../../lessons/straight-lines.html). Import [lesson.json](../../../lessons/straight-lines/lesson.json) into [Lesson Studio](../../../lesson-studio.html) to edit it. The learner export is independently runnable; it is not the editable application.

Suitable for Stage 5, Years 9–10, with signed arithmetic and coordinate plotting already familiar. Allow two classroom sessions, or use one skill per session. Students need an exercise book, ruler and squared paper. Responses default to paper; the shared typed and pen modes remain available to an author.

The sequence is overview → outcomes → gradient → y-intercept → rule to graph → completion. Each skill has a short introduction, a collection of examples, guided completion and independent practice. Empty optional video slots remain in the editor and are omitted from the learner sequence. No teacher URLs, timing or transcripts have been supplied.

Gradient starts with a positive integer rate, moves to negative and zero rates, then compares magnitudes on equal-scale axes. The undefined gradient of a vertical line appears in independent practice. The y-intercept skill distinguishes a scalar intercept from its coordinate and connects the table column at x = 0 with the constant in y = mx + c. The final skill uses a table and a fractional gradient to plot restricted straight-line segments.

The symbols m and c are explicitly introduced in the skill notes before use in the examples. They represent gradient and y-intercept; they are not extra numeric helper variables. Graph captions identify solid/dashed functions. The final two figures use the existing segment object to show mathematical domain endpoints; the graph window is only a viewing window and may expand to fit labels and equal scales.

Ask students to describe a gradient's sign before calculating, locate x = 0 when finding an intercept, and check a third plotted point by substitution. For extension, reverse a pair of points and show the same gradient, or compare two rules with the same intercept. Midpoint, distance and perpendicular-line equations require separate teaching and are not claimed as covered here.
